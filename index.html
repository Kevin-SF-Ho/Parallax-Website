視差滾動效果

作者：Vineet Kumar

什麼是視差滾動？

視差滾動是一種網頁設計技巧，讓網站背景以比前景更慢的速度移動。 當訪客往下捲動頁面時，會產生 3D 視覺效果，帶來深度並創造更沉浸的瀏覽體驗。 這種效果源自視覺錯覺：人眼會覺得近處的物體比遠處的更大，也因此覺得遠處物體移動得更慢。 這項錯覺長期被運用在各種媒介以營造更真實的效果，最早可追溯至迪士尼《白雪公主》 等傳統動畫以及《超級瑪利歐》等電玩遊戲。隨著 CSS 與 HTML 技術的進步， 視差效果也逐漸演進為我們今天熟悉的網頁設計手法。

其中一個最早的瀏覽器視差滾動實作，是開發者 Glutnix 在 2007 年的部落格文章中分享， 使用 JavaScript 和 CSS 2 示範，甚至支援當時的 Internet Explorer 6。 不過直到 2011 年、HTML5 與 CSS3 普及後，這項技術才在網頁設計師間流行起來。 擁護者認為這是展現網頁流動性的簡單方式，並將視差背景作為提升互動與體驗的工具。 然而，普渡大學 2013 年的研究指出：「儘管視差滾動提升了使用者體驗的某些面向， 但未必能改善整體使用者體驗。」


為什麼要使用視差圖形？

    設計師嘗試視差圖形有兩個主要原因：

  • 有助於說故事

    視差圖形非常適合用來說故事。好的設計在於溝通，打造網站時，我們希望與訪客交流， 說出關於產品、服務或品牌的精彩故事。視差滾動能讓訪客沉浸在獨特的線上體驗中， 甚至可以打造單頁式網站，讓訪客無須切換頁面就能閱讀完整故事。

  • 能提升使用者互動

    視差圖形能提升使用者互動。降低網站跳出率是網頁設計的重要目標之一。 跳出率代表使用者只看了單頁就按「返回」或關閉分頁的比例，跳出率過高會影響搜尋排名， 因此任何能降低跳出率的做法都值得嘗試。精心設計的視差頁面能帶來更動態的體驗， 讓使用者停留更久。


想在網站加入視差滾動效果時，請考慮以下技巧：

  • 有選擇地使用

    視差滾動用在單一元素時效果更佳，而非所有頁面都套用。 你可以在標題或首頁加入效果，讓視差強化設計而不分散使用者注意力。

  • 圖片壓縮

    視差滾動會使用多種媒體檔與 CSS 形狀來打造深度。 不要讓過大的圖片拖慢載入速度、犧牲效能與使用者體驗。

  • 善用色彩

    視差滾動不僅僅是前景與背景的圖片，也包含色彩的運用。 背景可使用較低彩度的顏色，前景則搭配更鮮明的色調，營造更強的深度感。
